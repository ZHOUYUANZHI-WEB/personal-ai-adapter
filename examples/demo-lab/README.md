# Demo AI Lab

This is a fictional, sanitized instance used to demonstrate the Personal AI Adapter data contracts. It contains no real personal information, credentials, or live external identifiers.

The example shows an incomplete idea entering Inbox, an active Project preserving a recovery point, two Context Profiles, and explicitly linked Knowledge. It can be used directly with the context command:

```bash
pai context project-personal-ai-adapter --agent codex --lab examples/demo-lab
```
